One-line roast of the gadget I use every day — my smartwatch:

> My smartwatch cheered when I stood up, then silently watched me sit for the next nine hours.

Why it wins against the brief: it roasts a daily gadget with one concrete, specific gripe instead of a generic insult. The watch celebrates a single stand, then says nothing about nine hours of sitting — the praise is absurdly cheap, which is funny on first read. The angle is fresh (not the dead-battery complaint everyone makes), the wording is neat, and it reads as one person's real daily experience.

## Run it

```sh
python3 main.py
```

This writes the single roast line to `/output/entry.txt`.
